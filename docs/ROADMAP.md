# Roadmap

## v0.1 — Foundation (included)

- Product identity and responsive Mini App UI.
- Startale connector and Farcaster lifecycle.
- Manifest and media assets.
- Core protocol, mock token, unit tests and deployment script.
- Typed SDK and one access-check example.

## v0.2 — Real Minato flow

- Deploy and verify contracts.
- Replace demo plans with onchain plan reads.
- Add wallet balance, vault balance and transaction receipts.
- Use batched calls where the Startale host supports them.
- Build merchant plan creation form.
- Add keeper service and event indexer.

## v0.3 — Security release candidate

- Foundry fuzz/invariant tests.
- Property-based accounting tests.
- Plan metadata signature and merchant domain verification.
- Refund dashboard.
- Monitoring and alerting.
- Second example integration: creator club.

## v1.0 — Submission candidate

- Independent audit findings resolved.
- Cloudflare production deployment.
- Startale manifest/embed/sandbox validation.
- Verified Soneium contracts.
- Documentation and two-minute demo.
- Pilot Mini App integration.
